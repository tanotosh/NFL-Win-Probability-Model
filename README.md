# NFL Win Probability Model

## Website
https://tanotosh.github.io/NFL-Win-Probability-Model/

## Project Description
The aim of this project is build a machine learning model to predict the win probability of an NFL (National Football League) team given the current game statistics. Key features include field position, time remaining, score difference. Additionaly, our model will take into account the offensive and defensive team strengths based on historical performance. Theses variables are the foundations for training a machine learning model that estimates the win probability on a play-by-play basis during an NFL game.
